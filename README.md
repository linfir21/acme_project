# ACME Birthday Tracker

Учебный проект из Яндекс Практикума (9 спринт): веб-приложение для учёта дней рождения на Django.

Пользователи регистрируются, добавляют записи о днях рождения (с фотографией и тегами), видят обратный отсчёт до ближайшего дня рождения и оставляют друг другу поздравления. Автор записи может её редактировать и удалять. Письма (сброс пароля, уведомления) сохраняются в файлы в папке `sent_emails/`.

## Стек

- Python 3.14
- Django 6.0
- django-bootstrap5 24.2 — стилизация форм под Bootstrap 5
- django-debug-toolbar 6.2 — панель отладки
- Pillow 12.1 — работа с изображениями
- SQLite (база данных по умолчанию)

## Возможности

- Регистрация и аутентификация пользователей (включая сброс/смену пароля)
- Список записей о днях рождения с пагинацией (10 на страницу)
- Создание, редактирование и удаление записей (только автором)
- Уникальность записи по набору «имя + фамилия + дата рождения»
- Валидация возраста (от 1 до 120 лет)
- Загрузка фотографий к записям
- Теги для записей
- Обратный отсчёт до следующего дня рождения (с учётом 29 февраля)
- Поздравления-комментарии к записям
- Счётчики запросов к БД через `select_related` / `prefetch_related`
- Обработчики страниц 404 и ошибки CSRF
- Фича «Битлз»: если ФИО совпадает с именем участника группы Beatles, запись блокируется, а администратору отправляется письмо

## Установка и запуск

```bash
# 1. Клонируйте репозиторий и перейдите в папку проекта (там, где лежит manage.py)
git clone https://github.com/linfir21/acme_project.git
cd acme_project/acme_project

# 2. Создайте виртуальное окружение и установите зависимости
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux/macOS
pip install -r requirements.txt

# 3. Примените миграции и создайте суперпользователя (опционально)
python manage.py migrate
python manage.py createsuperuser

# 4. Запустите сервер разработки
python manage.py runserver
```

После запуска:

- Сайт: <http://127.0.0.1:8000/>
- Админка: <http://127.0.0.1:8000/admin/>
- Панель отладки: <http://127.0.0.1:8000/__debug__/> (только при `DEBUG=True`)

## Примечания

- `SECRET_KEY` в `settings.py` захардкожен — это учебный проект. Для продакшена ключ следует вынести в переменные окружения и отключить `DEBUG`.
- Письма сохраняются в файлы (`EMAIL_BACKEND = filebased`) в папке `sent_emails/`.
- Загруженные пользователями изображения попадают в `media/birthdays_images/`.
